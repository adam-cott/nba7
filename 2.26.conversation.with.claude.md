# Session Notes — February 26, 2026

## What We Did

### 1. Parallelized the Sentiment Pipeline
Continued from previous session. Implemented chunked `Promise.all` for YouTube API calls in `src/app/api/news/route.ts`:
- `SENTIMENT_CONCURRENCY = 6` (started at 4, bumped after testing)
- Pre-allocate results array with indexed assignment to preserve article order
- First pass handles cached items instantly; second pass processes stale items in chunks of 6
- Parallel comment writes with `Promise.all` (Option 3)
- Same pattern applied to in-memory fallback path
- Removed 200ms artificial delay between YouTube calls
- Result: ~15s cold load → ~4s on Vercel production

### 2. Fixed Dedup Bug
`news-fetcher.ts` — Added `'nba'` to `DEDUP_STOP_WORDS`. 'NBA' appeared in virtually every headline, causing unrelated articles to hit the `MIN_SHARED_ENTITIES=2` threshold when paired with any other common term (e.g. 'All-Star'). Was incorrectly dropping Power Rankings articles.

### 3. Bug Audit
Ran full project audit. Found and fixed 2 real bugs:
- **Image container bug** (`ArticleCard.tsx`, `HeroArticle.tsx`): `onError` was hiding the `<img>` but leaving the parent `<div>` visible (gray rectangle). Fixed to hide the parent container.
- **`formatDistanceToNow` crash** (`ArticleCard.tsx`, `HeroArticle.tsx`): Called without try/catch — invalid `published_at` would crash the component render. Added try/catch consistent with comment components.
